# 🔱 Currency Converter

Учебный пет-проект: простой конвертер валют для конвертации сумм между различными валютами.

## ⚒️ Стек технологий

- **HTML5** — семантическая разметка
- **Sass/SCSS** — стилизация приложения
- **Vanilla JS (ES6+)** — логика конвертера и работа с DOM
- **Vite** — сборщик проекта и dev-сервер

## 📌 Функционал приложения

- [ ] Выбор исходной и целевой валюты
- [ ] Ввод суммы для конвертации
- [ ] Расчет и отображение итоговой суммы
- [ ] Быстрый обмен валют местами (Swap)
- [ ] Очистка/сброс введенных данных
