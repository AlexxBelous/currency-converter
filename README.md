# ⚡ Vite Vanilla SCSS Starter Template

Минималистичный шаблон (Boilerplate) для быстрого старта пет-проектов на чистом JavaScript, SCSS и HTML с использованием сборщика Vite.

## 🛠️ Стек технологий

- **Vite** — сверхбыстрый сборщик проектов и dev-сервер
- **Vanilla JS** — чистый JavaScript (ES Modules)
- **Sass/SCSS** — препроцессор стилей
- **HTML5**

---

## 📁 Структура проекта

```text
├── public/
│   └── js-logo.svg         # Иконка вкладки (favicon)
├── src/
│   ├── main.js             # Главный JS-файл (импортирует стили)
│   └── main.scss           # Главный файл стилей SCSS
├── .gitignore              # Исключения для Git
├── index.html              # Основная HTML-разметка
├── package.json            # Зависимости и скрипты
└── README.md               # Документация проекта
```

## 🚀 Как использовать этот шаблон

### 1. Создание репозитория из шаблона

1. Нажми зеленую кнопку **«Use this template»** $\rightarrow$ **«Create a new repository»** в верхней части страницы этого репозитория на GitHub.
2. Введи название для своего нового проекта и создай репозиторий.

### 2. Клонирование и запуск в VS Code

1. Открой терминал и клонируй новый репозиторий:
   ```bash
   git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
   ```
2. В терминале:

```bash
npm install
```

```bash
npm run dev
```
